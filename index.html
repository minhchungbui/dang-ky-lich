Thông số Supabase

Các bước cài Supabase (bấm để mở)
  1. Vào supabase.com → đăng ký miễn phí → New project. Đặt mật khẩu database và chọn region Singapore.
  2. Mở SQL Editor → New query → dán toàn bộ đoạn SQL bên dưới → bấm Run.
  3. Vào Project Settings → API, chép Project URL và anon public key vào hai ô ở trên.
  4. Bấm Lưu cài đặt rồi Kiểm tra kết nối.

Gửi cho nhân viên điền

      
Cách gọn nhất: đưa file này lên GitHub Pages (miễn phí, có link https), rồi gửi link kèm cấu hình cho nhân viên.

      

        
        
        
      

      

      

        Cách đưa lên GitHub Pages trong 5 phút (bấm để mở)
        
    
          
  1. Vào github.com → đăng ký/đăng nhập → New repository. Đặt tên ví dụ lich-lam-viec, chọn Public, bấm Create.
    2. 
          
  2. Trong repo vừa tạo bấm Add file → Upload files, kéo thả file index.html này vào, bấm Commit changes.
    3. 
          
  3. Vào Settings → Pages. Mục Source chọn Deploy from a branch, branch main, thư mục / (root), bấm Save.
    4. 
          
  4. Đợi 1–2 phút, GitHub hiện link dạng https://<tên-tài-khoản>.github.io/lich-lam-viec/.
    5. 
          
  5. Mở link đó, vào tab Cài đặt, điền lại thông số, bấm Tạo link cho nhân viên và gửi link đó cho mọi người. Link đã kèm sẵn cấu hình, nhân viên chỉ việc mở và điền.
    6. 
        

        
Cách khác nếu không thích GitHub: kéo thả file vào app.netlify.com/drop — có link ngay, không cần tài khoản. Hoặc gửi thẳng file index.html qua Zalo/email và dùng chế độ Chỉ máy này + Gửi bằng mã.
