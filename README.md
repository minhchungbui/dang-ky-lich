# Đăng ký lịch làm việc

Trang đăng ký lịch làm việc theo tháng. Nhân viên chọn ngày và khung giờ, quản lý xem
bảng tổng hợp.

Toàn bộ ứng dụng nằm trong một file `index.html` duy nhất, không cần cài đặt gì.

## Dùng thế nào

Mở link của trang, nhập họ tên, bấm vào các ô ngày để chọn, chỉnh giờ nếu cần, rồi bấm
**Gửi lịch làm việc**. Muốn sửa lại thì nhập đúng họ tên như lần trước, bấm **Tải lịch
đã gửi**, sửa xong bấm **Cập nhật**.

Dùng được trên điện thoại.
